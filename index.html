Akiba SACCO USSD emulator

The dial line opens pre-filled with *144#, so you can press Call straight away, or press * to start over and key it in yourself. End quits at any time.

Keyboard

0–9, *, # as on the keypad. Enter is Call, Esc is End, Backspace is Back.

On amount and phone screens, 0 is a digit; hold the 0 key to go Back.
